# ekbatan-rs

The Rust port of [Ekbatan](https://github.com/ekbatan-io/ekbatan): sharded persistence with
events written in the same transaction, on PostgreSQL, MySQL and MariaDB. Early work; see
[docs/LEDGER.md](docs/LEDGER.md).

```sh
cargo test   # needs Docker: runs on PostgreSQL, MySQL and MariaDB
```
